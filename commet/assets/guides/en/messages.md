## Reply, react and start a thread

Hover over a message to see its buttons. On a phone, press and hold the message.

- **Reply** quotes the message above yours, so people know what you're answering.
- **React** adds an emoji under the message. Click someone else's reaction to add yours.
- **Thread** starts a side conversation, so a long back-and-forth doesn't bury the room.

## Edit or delete your messages

Your own messages have **Edit** and **Delete** in the same menu. People can see that a message was edited.

## Mentions, emoji and GIFs

Type **@** and a name to mention someone; they get notified. Type **:** and a word for emoji. The buttons next to the message box add emoji, stickers, GIFs and files.
