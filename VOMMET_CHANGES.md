# Vommet changes compared with Commet

Everything this fork changes relative to upstream [Commet](https://github.com/commetchat/commet),
so the fork stays auditable and easy to rebase. **Rule: every change to Commet's code or
behaviour adds an entry here in the same commit.** Issue numbers refer to
[this repo's tracker](https://nether.codes/robocub/vommet/issues).

Status: **main** = merged; **testing** = on the [`testing`](https://nether.codes/robocub/vommet/src/branch/testing)
branch (in tester builds) and on its own branch, waiting for hands-on testing before it is merged.
