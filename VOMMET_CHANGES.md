# Vommet changes compared with Commet

Everything this fork changes relative to upstream [Commet](https://github.com/commetchat/commet),
so the fork stays auditable and easy to rebase. **Rule: every change to Commet's code or
behaviour adds an entry here in the same commit.** Issue numbers refer to
[this repo's tracker](https://nether.codes/robocub/vommet/issues).

Status: **main** = merged; **testing** = on the [`testing`](https://nether.codes/robocub/vommet/src/branch/testing)
branch (in tester builds) and on its own branch, waiting for hands-on testing before it is merged.

## Identity and separation from Commet's infrastructure

| Change | Where | Status |
|---|---|---|
| Application id `chat.commet.commetapp` → `im.nether.chat` on Android, Linux and Windows (installs beside Commet); Android Kotlin package moved | android/, linux/, windows/, msix config | main |
| Linux builds use the production app id `im.nether.chat` (`COMMET_PROD=1`; CI built `im.nether.chat.develop`, so docks showed no icon) and the X11 window class is the app id (`g_set_prgname`) | `linux/main.cc`, Linux CI workflows | testing (`fix/linux-app-id`, `ci/flatpak`) |
| Third-party proxy default `proxy.commet.chat` → `proxy.nether.im` ([vommet-proxy](https://nether.codes/robocub/vommet-proxy)) | `config/preferences.dart` | main |
| Update checker disabled (`UpdateChecker.hasReleaseFeed = false`): Commet's feed describes Commet, and Windows auto-update would replace the fork with Commet | `utils/update_checker.dart` | main |
| `push.commet.chat` removed from the push-gateway choices (it serves Commet's Firebase project) | notification settings | main |
| Default push gateway `push.commet.chat` → `matrix.gateway.unifiedpush.org` (UnifiedPush builds); pushers on the old default re-register on next start | `config/preferences.dart` | testing (`fix/own-push-gateway`) |
| README: fork disclosure, slogan, changes and plans, footer | `README.md` | main |
| Name "Vommet" everywhere (window title, app labels, desktop entries, Windows resources, English strings); executable `vommet` | many | testing (`chore/branding`) |
| Logo (Twemoji 🤮/🤩 adaptation, CC-BY 4.0) and all platform icons, generated by `scripts/generate_vommet_icons.py` from `vommet.svg` / `vommet-mono.svg` | `assets/images/app_icon/`, platform icon dirs | testing (`chore/branding`) |
| "Source Code" / "License" links and both in-app bug reporters point at nether.codes instead of Commet's GitHub (`BuildConfig.sourceUrl`, `issueHost`, …) | about page, log page, crash screen | testing (`chore/branding`) |
| Donations: Settings "Donate" entry and the post-update "please donate" dialog removed (their flow went to commet.chat) | settings, main page | testing (`chore/fork-settings`) |

## Deliberately unchanged

- Matrix event types and account-data keys under `chat.commet.*` (calendars, photo albums, recent emoji, sidebar order…), so data stays compatible with Commet.
- The `commetchat://` URL scheme (widget deep links), Flutter MethodChannel names, and the Rust library name `rust_lib_commet`.
- Strings that credit or point to Commet on purpose (README credits, "donate to Commet" text in profile badges).
